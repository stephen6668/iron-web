# IRON Web

Dein Iron-Assistent im Handy-Browser: Sprache und Text, Aufgaben, Pläne, Einkauf, Ideen, eigene Termine, Gedächtnis und Nachrichten aus direkten Quellen.

Die neue Cloud-Betriebsart läuft unabhängig vom PC. Dafür muss der enthaltene Node-24-Server einmalig mit HTTPS und dauerhaftem Speicher gehostet werden. **Hosting und KI-Schlüssel sind noch nicht eingerichtet; der neue Cloud-Betrieb ist noch nicht live.** Die bisherige private PC-Verbindung bleibt auswählbar.

- [Cloud einrichten und Funktionsumfang](README_CLOUD.md)
- [GitHub Pages und bisherige PC-Verbindung](README_GITHUB_PAGES.md)

Lokal prüfen: `npm ci`, `npm test`, `npm run check`. Start und Konfiguration stehen in der Cloud-Anleitung. Reale Schlüssel gehören ausschließlich in die Server-Konfiguration, niemals ins Repository.
