# IRON v18 – Appwrite Cloud

Die Website verwendet Appwrite Cloud als dauerhafte Datenverbindung.

## GitHub Pages
Lade diese Dateien hoch:
- `index.html`
- `plans.html`
- `task.html`
- `style.css`
- `app.js`
- `appwrite-config.js`
- `appwrite-cloud.js`

Die Webseite benötigt keinen Cloudflare-Quick-Tunnel mehr für Tasks, Plans, Login und PC-Status. PC-spezifische Befehle werden über `pccommands` an den lokalen PC-Agenten übergeben.
