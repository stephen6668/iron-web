# IRON Web V23.11 – Antworten vorlesen

Die Webseite liest IRON-Antworten nun über die Sprachausgabe des Browsers vor.
Sie braucht dafür keine neue Cloud-Route oder kostenpflichtige Voice-API.
Das gilt auch für Antworten auf getippte Befehle und für die bestehende
News-Welt-Vorlesefunktion. Lange Antworten werden in Abschnitten gelesen.

## Installation auf GitHub Pages

Alle Dateien dieses ZIP in das bestehende GitHub-Pages-Repository der
IRON-Webseite kopieren und veröffentlichen. Danach die Seite neu laden,
gegebenenfalls mit `Strg+F5`.

Unten rechts steht `🔊 STIMME AN`. Ein Klick schaltet die Sprachausgabe aus;
erneutes Klicken aktiviert sie und spielt eine kurze Probe. Diese Wahl wird
im Browser gespeichert. Die erste Wiedergabe kann je nach Browser einen
Klick auf die Seite erfordern. Als Sprache wird eine verfügbare deutsche
Browser-/Systemstimme bevorzugt; Klang und Verfügbarkeit hängen vom Gerät ab.

Zum Testen auf der Startseite einen Befehl wie „IRON, wie geht es dir?“
eintippen und absenden. Die Antwort muss als Text erscheinen und vorgelesen
werden. Bei blockierter Wiedergabe den Stimmschalter aus- und wieder einschalten
und Browser-Ton/Stummschaltung prüfen.

Die Cloud- und Appwrite-Einstellungen sowie die SMS-Funktionen bleiben wie
bisher. Nur die Webseite wird aktualisiert; PC und Android brauchen für diese
Änderung kein Update.
